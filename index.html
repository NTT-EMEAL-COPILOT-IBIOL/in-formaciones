D Manual para Primeros Usuarios de Devin

Guia completa de inicio: desde la configuracion hasta el uso avanzado.

1. Que es Devin

Ingeniero de software autonomo con IA de Cognition AI. Puede escribir codigo, ejecutar comandos en Linux, crear PRs, navegar la web, probar su trabajo y trabajar en paralelo.

⚡
Regla de complejidad: Si una tarea te tomaria 3 horas o menos, Devin probablemente puede hacerla. Para tareas mas grandes, divide en sesiones enfocadas y ejecuta en paralelo.

📚

💻

Repo Setup (8 pasos)

Git Pull, Secrets, Install Deps, Maintain Deps, Lint, Tests, Run App, Notes

4. Ask vs Agent

💬 Ask (Preguntar)

Modo ligero para explorar codebase y planificar. No hace cambios de codigo.

  • Preguntas sobre arquitectura
  • Explorar dependencias
  • Generar prompts con contexto

🤖 Agent (Agente)

Modo autonomo completo. Escribe codigo, ejecuta comandos, crea PRs.

  • Implementar features
  • Corregir bugs
  • Ejecutar tests

Tipos de agente: Devin (general)   Fast (tareas rapidas)   Dana (data analyst)

7. Knowledge

Coleccion de tips e instrucciones que Devin consulta automaticamente en todas las sesiones.

  • Crear: Settings > Knowledge > Add Knowledge
  • Macros: Asigna un nombre (ej: !deploy-checklist) para referencia rapida
  • Fijar a repos: Sin repo (relevancia), repo especifico (siempre), todos los repos (global)

8. Playbooks

Prompts reutilizables y compartibles para tareas repetidas. Estructura recomendada:

## Overview          — Resultado esperado
## What's Needed     — Inputs del usuario
## Procedure         — Pasos paso a paso
## Specifications    — Postcondiciones
## Advice            — Tips
## Forbidden Actions — Lo que NO debe hacer

6 Update microservices Manager Migración y actualización de microservicios a nuevas versiones tecnológicas.
7 TI - Teams meet resume Genera actas estructuradas de reuniones con puntos clave y próximos pasos.
8 Testing Microfrontend v2 Generación de tests unitarios para microfrontends con cobertura mínima y métricas.
9 TI - SonarQube Code Smells - Analysis & Fix Análisis y corrección automática de code smells, generando PRs y reportes.

1. Que es Windsurf

IDE con IA integrada creado por Codeium, basado en VS Code. A diferencia de una extension, la IA esta integrada en el nucleo del editor. La IA puede tomar acciones: crear archivos, ejecutar comandos, instalar dependencias y editar multiples archivos coordinadamente.

  • Accept / Accept All — Acepta cambio(s)
  • Reject — Rechaza cambio
  • Stop — Detiene Cascade
  • Retry — Reintenta
💡
Cascade vs Chat: Usa Cascade para features, refactoring y bugs complejos (edita multiples archivos, ejecuta comandos). Usa Chat para preguntas, explicaciones y sugerencias (solo responde, no modifica).
