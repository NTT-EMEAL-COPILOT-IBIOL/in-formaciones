PARTE I — DEVIN

Manual para Primeros Usuarios • Ingeniero de Software Autonomo con IA

D Manual para Primeros Usuarios de Devin

Guia completa de inicio: desde la configuracion hasta el uso avanzado.

1. Que es Devin

Ingeniero de software autonomo con IA de Cognition AI. Puede escribir codigo, ejecutar comandos en Linux, crear PRs, navegar la web, probar su trabajo y trabajar en paralelo.

⚡
Regla de complejidad: Si una tarea te tomaria 3 horas o menos, Devin probablemente puede hacerla. Para tareas mas grandes, divide en sesiones enfocadas y ejecuta en paralelo.

4. Ask vs Agent

💬 Ask (Preguntar)

Modo ligero para explorar codebase y planificar. No hace cambios de codigo.

  • Preguntas sobre arquitectura
  • Explorar dependencias
  • Generar prompts con contexto

🤖 Agent (Agente)

Modo autonomo completo. Escribe codigo, ejecuta comandos, crea PRs.

  • Implementar features
  • Corregir bugs
  • Ejecutar tests

Tipos de agente: Devin (general)   Fast (tareas rapidas)   Dana (data analyst)

7. Knowledge

Coleccion de tips e instrucciones que Devin consulta automaticamente en todas las sesiones.

  • Crear: Settings > Knowledge > Add Knowledge
  • Macros: Asigna un nombre (ej: !deploy-checklist) para referencia rapida
  • Fijar a repos: Sin repo (relevancia), repo especifico (siempre), todos los repos (global)

8. Playbooks

Prompts reutilizables y compartibles para tareas repetidas. Estructura recomendada:

## Overview          — Resultado esperado
## What's Needed     — Inputs del usuario
## Procedure         — Pasos paso a paso
## Specifications    — Postcondiciones
## Advice            — Tips
## Forbidden Actions — Lo que NO debe hacer

Checklist del Primer Dia con Devin

  • Acceder a app.devin.ai y verificar credenciales
  • Indexar los repositorios principales del equipo
  • Configurar el entorno (Repo Setup) para al menos 1 repo
  • Configurar Secrets necesarios (API keys, credenciales)
  • Conectar integracion de Slack
  • Hacer tu primera pregunta con Ask Devin
  • Ejecutar tu primera sesion Agent con tarea pequena
  • Revisar Session Insights de tu primera sesion
  • Crear al menos un Knowledge con convencion del equipo
  • Explorar el MCP Marketplace
  • Configurar Devin Review para auto-review

Manual para Primeros Usuarios • IDE con IA Integrada por Codeium

F Manual para Primeros Usuarios de Windsurf

Guia completa de inicio y uso efectivo del IDE con IA.

1. Que es Windsurf

IDE con IA integrada creado por Codeium, basado en VS Code. A diferencia de una extension, la IA esta integrada en el nucleo del editor. La IA puede tomar acciones: crear archivos, ejecutar comandos, instalar dependencias y editar multiples archivos coordinadamente.

4. Cascade: El Agente IA

Abrir: Cmd/Ctrl+Shift+L

Que puede hacer

  • Leer y analizar multiples archivos
  • Crear y editar archivos
  • Ejecutar comandos en terminal
  • Instalar dependencias
  • Iterar sobre errores

Controles

  • Accept / Accept All — Acepta cambio(s)
  • Reject — Rechaza cambio
  • Stop — Detiene Cascade
  • Retry — Reintenta
💡
Cascade vs Chat: Usa Cascade para features, refactoring y bugs complejos (edita multiples archivos, ejecuta comandos). Usa Chat para preguntas, explicaciones y sugerencias (solo responde, no modifica).

6. Edicion Inline

Selecciona codigo → Cmd/Ctrl+I → Escribe instruccion → Revisa diff → Acepta/Rechaza

Ideal para: Agregar tipos TS, convertir funciones, agregar validacion, optimizar rendimiento, agregar logging.

7. Chat con IA

Abrir: Cmd/Ctrl+L. Referencias: @archivo para contexto, @codebase para proyecto completo.

Preguntas utiles: Comprension ("¿Que hace esto?"), Planificacion ("¿Como implementar cache?"), Debugging ("¿Por que falla este test?")

8. Flows: Memoria Persistente

Recuerda contexto entre sesiones: archivos visitados, cambios realizados, decisiones tomadas. Accede desde la pestana History.

Cuando Usar Cada Herramienta

🤖 Usa Devin cuando...

  • Puedes delegar completamente la tarea
  • Necesitas automatizacion recurrente
  • Quieres paralelizar trabajo
  • Necesitas code review automatico
  • Haces migraciones a escala
  • Necesitas respuesta a incidentes
  • No estas en tu IDE (via Slack, web)

🌬 Usa Windsurf cuando...

  • Haces desarrollo interactivo diario
  • Necesitas autocompletado en tiempo real
  • Quieres ediciones rapidas con Cmd+I
  • Exploras codebase nuevo
  • Haces refactoring guiado
  • Necesitas debugging interactivo
  • Quieres control total sobre el codigo

Flujo Combinado Recomendado

1. PLANIFICACION
Windsurf
Chat para explorar codebase, planificar arquitectura
2. IMPLEMENTACION
Windsurf
Supercomplete + Cascade + Inline Edit + debugging interactivo
3. DELEGACION
Devin
Genera tests, corrige vulnerabilidades, migraciones a escala, documentacion
4. REVISION
Devin
Devin Review + Bug Catcher + Auto-Fix + CI iteration
5. AUTOMATIZACION
Devin
Sesiones programadas, triage de errores, actualizacion de dependencias
💡
Recomendacion: Windsurf y Devin son complementarios. Usa Windsurf para desarrollo interactivo diario y Devin para delegar tareas completas autonomamente. Juntos maximizan la productividad del equipo.
